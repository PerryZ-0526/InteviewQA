# 构建 RAG 系统

> <span style="font-size: 12pt">构建 RAG 系统：支持多种文档格式导入及复杂表格处理，采用结构感知的父子文档切块以保证政策条目完整及语义连续；根据首轮召回的证据覆盖度动态生成补充查询，自适应选择缺失维度补充、语义扩展、HyDE 等检索策略，提高复杂问题的召回完整性。</span>



> <span style="font-size: 12pt">基于 LangGraph 构建两层编排图：实时对话图集成 RAG 政策检索、学生画像、校内业务办理协助、资源推荐等，其中在线检索（导师推荐、期刊检索等）封装为 ReAct 子图，通过查询改写、补充检索与结果聚合完成多轮资源搜索；后台异步图驱动画像更新、资源推送、政策节点提醒及跨天 follow-up。</span>

项目使用 LangGraph 构建了两张独立的有状态编排图，分别处理实时对话和后台异步事件。LangGraph 在这里的核心价值是：管理复杂分支流程的状态流转、条件路由和可控循环，而不是作为简单的链式调用工具
